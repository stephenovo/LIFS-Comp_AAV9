# 实验验证交接 SOP

**项目：** LIFS-Comp_AAV9  
**版本：** 1.0  
**目的：** 验证计算筛出的 AAV9 7-mer 衣壳能否稳定生产，以及它们相对同背景亲本衣壳能否改善“中枢—肝脏”分布代理。

> 这是一份交给具备资质的 AAV 载体平台、细胞实验室和动物平台使用的研究设计与决策 SOP。细胞培养、转染、病毒纯化、给药、取材和废弃物处理，必须由接收单位按照自身已经验证的 SOP、风险评估、生物安全审批和动物伦理审批执行。本文档不能代替机构培训，也不构成开展实验的授权。

## 1. 这套实验究竟要证明什么

计算筛选得到的是“待验证假设”，不是疗法。每个计算结论必须对应一个实验读数：

| 计算结论 | 必须观察到的实验结果 | 阳性后最多可以怎么说 |
|---|---|---|
| 包装置信下界过线 | 载体产量可重复，产品质量合格 | 该变体在本生产流程中可以制备 |
| 预测小鼠脑/脊髓较高 | 中枢组织中的载体基因组、RNA 和报告蛋白信号 | 在本模型和条件下改善了中枢递送或表达 |
| 预测小鼠肝脏较低 | 同剂量下肝脏载体基因组和表达低于亲本 | 在本模型和条件下降低了肝脏暴露 |
| 预测 CNS:肝脏特异性高 | 预先定义的 CNS:肝比改善，而且 CNS 信号没有一起消失 | 实测分布更符合本项目目标 |
| 免疫足迹位点注释 | 使用个体血清的标准化中和实验 | 只能描述实测中和表型，不能泛化成“免疫逃逸” |

即使全部实验成功，也不能直接声称“具有人运动神经元特异性”“降低临床肝毒性”“治疗 SMA 有效”或“优于 Zolgensma”。

## 2. 开始前必须具备的审批和负责人

实验开始前，接收机构必须记录：

- 重组 AAV 项目的生物安全审查和场地风险评估；
- 动物实验伦理审批、监测计划、人道终点和处置规则；
- 若使用人源细胞或血清，相应的伦理、样本来源和使用审批；
- 载体生产、分析质控、细胞实验、动物实验、病理、统计和数据保管负责人；
- 冻结的实验方案版本、样本表、随机种子、排除规则和主要终点。

项目组负责候选依据和分析方案。接收平台负责细胞来源与代次、培养体系、转染方法、纯化流程、注射操作、麻醉安乐死和本地放行标准等具体程序参数。

## 3. 待测候选与对照

以 [`experimental_validation_panel.csv`](audit_data/experimental_validation_panel.csv) 为唯一权威样本表。

### 3.1 候选

- **第一阶段：** 30 条计算候选全部进入生产和质量检查。
- **Tier 1：** `GKEKGGE`、`KKDGQEG`、`QGSGKEG`、`VNKGKDE`、`KGDKNEG`、`SKDNKEG`、`GAKGGEG`。这 7 条通过了严格保守定义，应优先排期。
- **Tier 2：** 不属于 Tier 1，但位于严格帕累托前沿、脑和脊髓预测分别达到训练中位数、且预测 CNS:肝优势为正的候选。当前为 `QQKDKQA`。
- **Tier 3：** 高分、多样化的探索候选，也包括只因某个次要目标极端而进入帕累托前沿、但绝对 CNS 表现不足的边界案例。`RAKREEE` 属于这一类，不应仅凭帕累托标签优先推进。
- 预算允许时，每个 7-mer 可设计两种同义 DNA 编码，用于识别核苷酸或条形码效应。它们属于构建重复，不能替代独立生产批次和生物学重复。

### 3.2 必须设置的对照

1. **同背景亲本对照：** 不插入 7-mer 的 AAV9 `(K449R)`。Fit4Function 文库采用这一背景，所以它是主要比较对象。
2. **无载体/mock 对照：** 在所有适用阶段一起经历实验流程，用于估计背景。
3. **野生型 AAV9：** 可选的外部背景对照，不能替代 `(K449R)` 亲本。
4. **经验方向性对照：** 从 Fit4Function 审计表中按固定规则选出的高包装、低包装、高 CNS/低肝、高肝/低 CNS 各一条。这些用于检查实验方向是否正确，但属于训练数据内对照，不是独立验证。

同一轮比较中，所有衣壳必须包装完全相同的载体基因组，并按含基因组颗粒的实际输入量匹配。第一轮用报告基因筛衣壳；只有衣壳通过分布验证后，才进入 SMN1 载荷实验。

## 4. 盲法、随机化与批次设计

1. 由不参与样本处理的人分配盲码。主要分析锁定前，序列—盲码表只读保存，不向操作者开放。
2. 构建、生产顺序、实验板位置、组织处理和分析批次均随机化。
3. 候选与亲本尽量在同一生产批次体系内完成，不能让“衣壳身份”和“生产日期/操作者”重合。
4. 可能进入后续阶段的候选，目标是获得 3 个独立生产批次。同义构建不能代替独立生产批次。
5. 动物在符合纳入标准后随机分组；适用时平衡笼位、性别、窝别和给药顺序。给药标签、组织处理、成像和主要分析尽量保持盲法。
6. 所有偏离方案的情况必须在揭盲前登记。

## 5. 阶段 0：锁定方案并确认构建

### 输入

- 冻结的候选/对照样本表；
- 一个统一的报告基因载体设计；
- 平台批准的质粒系统和生产 SOP；
- 已填写的 [`WET_LAB_PREREGISTRATION_TEMPLATE.md`](WET_LAB_PREREGISTRATION_TEMPLATE.md)。

### 操作

1. 按接收平台的序列编号规则确认亲本序列、`K449R` 背景，以及 VP1 588/589 之间的目标插入位置。
2. 为每个样本建立构建图谱，记录肽序列、DNA 编码、质粒编号、批号和流转记录。
3. 在生产前测序确认完整工程区域，检查混峰、非预期替换、插入缺失和重排。
4. 所有衣壳固定使用同一报告基因、启动子、增强元件、poly(A)、基因组长度和纯化路线。
5. 生成盲码，操作者只拿到盲码。

### 阶段 0 门槛

只有序列身份正确、生产记录获批的构建才能进入下一步。失败构建应重做，不能静默替换或改名。

## 6. 阶段 1：生产与包装合格性

接收平台使用自己已经验证的 AAV SOP 完成生产、收获、纯化、制剂和储存。Addgene 的 HEK293 AAV 生产方案可作为公开参考，但不能覆盖本地验证流程。

### 每个生产批次必须记录

- 经验证的 qPCR 或 ddPCR 测得的含基因组颗粒滴度，并记录核酸酶处理和标准品/参考物；
- 条件允许时，用经验证的衣壳检测测定总衣壳颗粒；
- 基因组:衣壳比，以及平台可用时通过正交方法获得的满壳/空壳估计；
- 衣壳和载体基因组身份；
- 可见聚集、回收率、制剂、冻融历史和分析批次 QC；
- 与后续用途相匹配的无菌/生物负载、内毒素和支原体结果；
- 按生产规模归一化，并相对同轮亲本批次归一化的产量。

### 预先登记的项目门槛

下面是本项目默认值，不是通用放行标准。接收平台可以在揭盲前替换，但必须写明理由。

- 身份正确；
- 后续用途要求的 QC 全部通过；
- 至少 3 个独立批次中的 2 个，归一化含基因组颗粒产量达到同批亲本的 `0.5×`；
- 相比亲本没有明显的聚集、完整性或满壳/空壳异常；
- 关键结果在独立生产批次中重复。

必须保留连续数值和置信区间，不能只留下“通过/不通过”。

### 阶段 1 输出

按可重复性和产品质量排序。先推进 Tier 1，再考虑 Tier 2；Tier 3 只在预注册的多样性挑战或实测产品质量提供额外理由时补入。每个阶段 2 实验都必须保留亲本和 mock。

## 7. 阶段 2：细胞层面的目标与肝脏脱靶验证

### 细胞体系

至少包括：

- 经过质量确认的人 iPSC 来源运动神经元，或另一个充分表征的运动神经元模型；
- HepG2 和/或 THLE-2，用于和现有的人肝细胞标签衔接；
- 一个稳定、易转导的细胞系作为实验性能对照，但不能把它当作运动神经元靶向证据。

用平台已经验证的标志物和标准确认运动神经元身份及培养质量，例如 ChAT、ISL1/2、HB9/MNX1，以及活率和形态。记录供体、分化批次、成熟时间窗、代次/分化天数和细胞密度。

### 设计

1. 所有衣壳使用同一报告基因载体。
2. 在每种细胞体系中预先确定多水平的载体基因组输入范围，避免信号饱和和明显毒性。报告实际 `vg/cell`，不能默认 HEK293 的剂量范围适用于 iPSC 神经元。
3. 至少进行 3 次独立生物学实验。技术孔用于估计检测精度，不能增加生物学样本量。
4. 盲码在实验板上平衡分布，每块板都包含 mock 和亲本。
5. 用平台已验证的时间窗，预先定义一个摄取终点和一个较晚的表达终点。

### 读数

- 每个细胞或每个二倍体基因组中的载体基因组；
- 用经验证参考基因归一化的报告基因 RNA；
- 报告蛋白/荧光，并使用预先定义的图像分割方法；
- 细胞活率和形态；
- 运动神经元培养物中，报告信号与运动神经元标志物的共定位；
- 用载体基因组摄取量归一化表达，避免把“进入细胞”和“进入后表达”混为一谈。

### 阶段 2 决策规则

候选必须同时满足：

- 已通过阶段 1；
- 运动神经元信号至少不低于同背景亲本；
- 肝细胞摄取或表达不高于亲本，优先选择可重复下降的候选；
- 预先定义的运动神经元:肝脏比值改善；
- 没有明显活率损失；
- 在独立载体批次和独立生物学实验中重复。

根据实测目标—肝脏权衡选择 4–6 条进入阶段 3，不能继续只按原来的模型分数挑选。

## 8. 阶段 3：全身给药小鼠的分布与转导

动物实验必须有机构批准的方案并使用平台自己的操作程序。下文规定比较关系和测量项目，不规定注射或手术手法。

### 设计

- 检测阶段 2 选出的 4–6 条候选、同背景 `(K449R)` 亲本、mock，以及产品质量允许时的一条信息量较高的经验对照。
- 固定报告基因、实际给入的含基因组颗粒剂量、制剂、给药途径和处理方式。
- 当问题是“全身给药后的 CNS—肝脏分布”时采用静脉途径，以匹配项目假设。
- 按主要终点进行事先功效分析来确定组数。Fit4Function 的若干单变体跟进实验用了每组 5 只，这只能作为背景信息，不能自动成为本项目样本量依据。
- 平衡性别和预先定义的协变量；若只用单一性别或群体，必须说明理由。
- 纳入排除标准和人道终点在揭盲前锁定。

### 时间点

预算允许时设置两个概念上不同的终点：

1. **早期分布：** 尽量与 Fit4Function 两小时器官载体基因组标签衔接，直接检验模型所学的代理。
2. **稳定转导：** 约三周的后期终点，与来源论文的单变体跟进相衔接，检测载体基因组、RNA、报告蛋白、组织学和临床化学。

如果只能做一个时间点，必须在揭盲前选择，并明确因此无法回答哪一类问题。

### 组织和测量

预先列出脑区、颈/胸/腰段脊髓、肝、心、肾、脾、肺、审批允许时的背根神经节、血液/血清，以及方案要求的其他安全性组织。

检测：

- 每个二倍体基因组中的载体基因组，并设置组织特异的检测 QC；
- 转基因 RNA 和报告蛋白；
- 脊髓中报告信号与运动神经元标志物共定位，在解剖条件允许时单独分析前角；
- 肝脏组织学以及血清 ALT、AST、胆红素和平台认可的其他安全性指标；
- 盲法病理和图像定量；
- 以动物作为实验单位，不能把多个视野或多个 qPCR 孔当成多只动物。

### 主要终点

建议预先登记一个主要终点：

```text
log2 特异性 = mean(log2 脊髓信号) - mean(log2 肝脏信号)
```

脑可以作为关键次要终点；只有在看数据之前定义，才可以和脊髓合成。载体基因组、RNA 和蛋白必须分别分析，不能临时合成一个没有定义的总分。

### 阶段 3 默认成功规则

- 脊髓:肝脏比相对同背景亲本至少改善 `2×`；
- 脊髓信号在预先设定的界值下不劣于亲本；
- 肝脏信号不高于亲本；
- 预定义安全性指标不更差；
- 结果得到不止一种测量层支持，并且不是由单个异常值或单个生产批次驱动。

效应量门槛和非劣界值必须根据 pilot 方差在揭盲前最终确定。比值可能因为两个器官都下降而“变好”，所以必须同时要求脊髓信号保留。

## 9. 阶段 4：SMA 相关性和免疫表征

这两部分与衣壳筛选分开，只应在报告基因实验通过后进行。

### SMA 相关性

- 用亲本和入选衣壳包装相同设计的 SMN1 表达载体，并匹配 QC。
- 在 SMA 患者来源 iPSC 运动神经元中检测 SMN 蛋白、核内 gems 恢复、细胞健康和经验证的疾病相关表型。
- 若有充分理由进入 SMA 动物模型，预先定义分子、组织学、运动、存活和安全性终点。不能从报告基因分布直接推断治疗效果。

### 中和抗体实验

- 使用经验证的细胞中和实验、个体血清样本和匹配 AAV9 对照。
- 报告检测定义、中和滴度或 IC50 分布、检测限、样本来源和不确定性。
- 当前 `site_context_only` 只表示插入位点背景，不预测免疫逃逸。只有实测数据才支持序列特异的中和结论。

## 10. 统计分析

1. 采数前定义实验单位：生产可重复性用生产批次，细胞研究用分化/供体批次，体内研究用动物。
2. 技术重复只估计检测精度，不能虚增 `n`。
3. 按主要终点、具有科学意义的效应、pilot/文献方差、功效、alpha 和预计损耗确定样本量。
4. 报告单个观测值、效应量、95% 置信区间和精确样本量。
5. 统计模型必须反映批次和重复结构；适用时把生产批次、细胞分化批次作为区组或随机效应。
6. 多衣壳、多次要终点要控制多重比较，同时保留唯一的预注册主要比较。
7. 揭盲前定义低于检测限、缺失值、排除、数据转换和异常值处理规则。
8. 原始、处理后和分析就绪数据分开保存，不能覆盖原始测量。

将所有观测录入 [`wet_lab_results_template.csv`](audit_data/wet_lab_results_template.csv)，将阶段决策录入 [`wet_lab_decision_log.csv`](audit_data/wet_lab_decision_log.csv)。Excel 交接表包含相同的候选面板和录入字段。

## 11. 失败结果怎么解释

| 观察结果 | 可能含义 | 下一步 |
|---|---|---|
| 每个批次产量都低 | 包装预测失败，或构建与生产流程不兼容 | 停止；先核对身份，只在有明确流程理由时复做 |
| 产量好、运动神经元信号差 | 能包装和能到达目标是两件事 | 不再作为 SMA 方向候选推进 |
| CNS:肝比改善，但两者都下降 | 表面“特异”，实质没有保留目标递送 | 若不满足脊髓非劣要求则失败 |
| 肝下降，心/肾上升 | 发生脱靶再分配 | 检查全器官谱，不能称为更安全 |
| 细胞成功、小鼠失败 | 体外模型不能预测全身分布 | 以体内证据为主，并分析机制 |
| 一个批次成功、另一个失败 | 制造稳定性不足 | 暂停，排查批次/工艺交互 |
| 报告基因成功、SMN1 失败 | 性能依赖载荷 | 结论限定为报告基因，重新设计转化实验 |
| 中和表型改变、递送不改善 | 免疫表型与递送目标相互独立 | 分开报告，不能用免疫结果挽救失败衣壳 |

## 12. 接收实验室最终应交付什么

- 最终构建图谱和身份记录；
- 主要分析锁定后的盲码对应表；
- 完整生产批次记录和所有 QC 数值；
- 带单位和检测限的原始与处理后数据；
- 随机化、排除和方案偏离日志；
- 分析代码和软件版本；
- 动物伦理方案编号和 ARRIVE Essential 10 报告项目；
- 每条候选的签字阶段决策，包括失败候选。
